# Cinnanico Links

This repository contains the source files for Cinnanico's E-Girl link-in-bio page with a pastel shader background and glowing profile & link button.

[Cinnanico Links Demo](https://chaneldemonblaze.github.io/Cinnanico-Links/)

## Features
- Custom pastel shader background using Three.js
- Floating circular profile picture with pulsing pink & blue glow
- Main OnlyFans photo button with semi-transparent overlay text
- Animated call-to-action text below social media icons
- Responsive design for mobile and desktop
- Social media links: Instagram, TikTok, X, Throne, Twitch
- Cute, playful typography (`Emilys Candy`) with minimal glow accents

## How It Works
- **Shader Background:** Uses Three.js with a fragment shader to create a dynamic pastel mosaic animation.
- **Profile Picture Glow:** Floating circular profile image with pulsing glow via CSS animations.
- **Main OF Link:** Clickable photo button with overlay text “🩷My Exclusive Content🩷”, semi-transparent background, and subtle pulsing glow effect on the box.
- **Social Media Buttons:** Logos are displayed below the profile name and are clickable links.
- **CTA Text:** Animated “Come chat with me! ↓” text below social icons draws attention to the main OF button.
- **Responsive Design:** CSS media queries ensure layout and glow effects adapt well to mobile and desktop screens.
